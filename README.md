# FRASEK – FRAS BBQ kalkulator

Spletna aplikacija za sestavljanje menijev in cen na osebo.

## Datoteke
- `index.html` – aplikacija
- `firebase-config.js` – podatki tvojega Firebase projekta (uredi samo to)
- `firestore.rules` – kdo ima dostop (prilepi v Firebase konzolo)
- `sw.js`, `manifest.webmanifest`, ikone – namestitev na telefon in delo brez povezave

Dokler `firebase-config.js` vsebuje "VPIŠI", aplikacija dela brez prijave in hrani podatke samo na napravi.
